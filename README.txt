TAAL & MAATSCHAPPIJ TRAINER – GITHUB PAGES

1. Pak dit ZIP-bestand uit.
2. Maak op GitHub een nieuwe repository aan.
3. Upload index.html naar de hoofdmap van de repository.
4. Ga naar Settings > Pages.
5. Kies 'Deploy from a branch', branch 'main' en map '/ (root)'.
6. Sla op. Na publicatie is de app bereikbaar via:
   https://JOUWGEBRUIKERSNAAM.github.io/REPOSITORYNAAM/

De app bewaart voortgang lokaal in de browser waarin je oefent.
Gebruik dezelfde browser en hetzelfde apparaat om je voortgang te behouden.
