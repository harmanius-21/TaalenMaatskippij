GITHUB PAGES INSTALLEREN
1. Pak het ZIP-bestand uit.
2. Upload ALLE bestanden naar de hoofdmap (root) van één GitHub-repository.
3. Ga naar Settings > Pages.
4. Kies Deploy from a branch, branch main, map /(root), en sla op.
5. Open de gepubliceerde GitHub Pages-link via Chrome op je telefoon.
6. Kies in Chrome: menu (⋮) > App installeren of Toevoegen aan startscherm.

LET OP
- GitHub Pages gebruikt HTTPS, nodig voor installatie en offline-functionaliteit.
- Na de eerste keer laden kan de app offline werken.
- Voortgang wordt lokaal in de browser opgeslagen. Gebruik dezelfde browser/apparaat.
